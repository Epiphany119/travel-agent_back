## 3. PR#2: MCP Protocol 协议架构

### 3.1 协议分层

```
┌─────────────────────────────────────────────────────────────────────┐
│                         MCP 应用层                                    │
│                    (McpTool, McpServerInfo)                         │
├─────────────────────────────────────────────────────────────────────┤
│                      JSON-RPC 2.0 层                                │
│          (JsonRpcRequest, JsonRpcResponse, JsonRpcError)            │
├─────────────────────────────────────────────────────────────────────┤
│                        传输层                                         │
│                       (McpTransport)                                 │
│                      HTTP / WebSocket                                │
└─────────────────────────────────────────────────────────────────────┘
```

### 3.2 MCP Client 架构

```
McpClient
    │
    ├── weatherSession()     → McpSession (weather)
    ├── poiSession()         → McpSession (poi)
    ├── mealSession()        → McpSession (meal)
    ├── budgetSession()      → McpSession (budget)
    └── itinerarySession()   → McpSession (itinerary)
            │
            ▼
    ┌─────────────────────────────────────┐
    │           McpSession                  │
    │  - serverName                        │
    │  - serverUrl                         │
    │  - transport (McpTransport)          │
    │  - serverInfo (McpServerInfo)        │
    │  - tools (List<McpTool>)              │
    │                                       │
    │  + callTool(toolCall)                │
    │  + subscribeStream(taskId)           │
    │  + getTools()                        │
    └─────────────────────────────────────┘
            │
            ▼
    ┌─────────────────────────────────────┐
    │          McpTransport                │
    │  - webClient (WebClient)             │
    │                                       │
    │  + callTool(serverUrl, toolCall)    │
    │  + getServerInfo(serverUrl)         │
    │  + subscribeSse(serverUrl, taskId)  │
    └─────────────────────────────────────┘
```

## 5. 数据流架构

### 5.1 旅行规划流程

```
用户请求: "帮我规划北京3日游"
                │
                ▼
┌───────────────────────────────────────────────────────────────┐
│                     AI Agent (travel-web)                      │
│                                                                │
│  1. 意图识别 & 实体提取                                         │
│     - 目的地: 北京                                             │
│     - 天数: 3                                                  │
│                                                                │
│  2. 工具编排 (并行调用)                                         │
│     ┌─────────────────────────────────────────────────┐       │
│     │                                                  │       │
│     ├── weather.get_forecast(city="北京")             │       │
│     │         │                                      │       │
│     │         ▼ Weather Server :8081                   │       │
│     │         │                                      │       │
│     │         ▼ 和风天气 API                          │       │
│     │                                                  │       │
│     ├── poi.search(city="北京", keywords="景点")       │       │
│     │         │                                      │       │
│     │         ▼ POI Server :8082                       │       │
│     │         │                                      │       │
│     │         ▼ 高德地图 POI API                      │       │
│     │                                                  │       │
│     ├── meal.search(city="北京", keywords="餐厅")      │       │
│     │         │                                      │       │
│     │         ▼ Meal Server :8083 (委托 POI)          │       │
│     │                                                  │       │
│     └── budget.estimate(days=3, cities=["北京"])      │       │
│               │                                      │       │
│               ▼ Budget Server :8084                    │       │
│               │                                      │       │
│               ▼ (纯内存计算)                          │       │
│     └─────────────────────────────────────────────────┘       │
│                                                                │
│  3. 结果聚合 & 行程生成                                        │
│     - 合并天气 + 景点 + 餐饮 + 预算                            │
│     - LLM 生成自然语言行程                                      │
│                                                                │
└───────────────────────────────────────────────────────────────┘
                │
                ▼
        返回行程规划结果
```

## 7. 安全性设计

### 7.1 认证授权

| 层级 | 机制 | 说明 |
|------|------|------|
| API 网关 | JWT Token | 验证用户身份 |
| 服务间调用 | 服务账户 | MCP Server 间调用认证 |
| 外部 API | API Key | 第三方服务认证 |

### 7.2 敏感信息管理

```
敏感信息层级:
Level 1: 代码中 (禁止)
Level 2: 配置文件 (不推荐)
Level 3: 环境变量 (推荐)
Level 4: 密钥管理服务 (生产推荐: AWS Secrets Manager / HashiCorp Vault)
```

### 7.3 API Key 配置

| 服务 | 环境变量 | 说明 |
|------|----------|------|
| 智谱 AI | `ZHIPU_API_KEY` | LLM 调用 |
| 和风天气 | `WEATHER_API_KEY` | 天气预报 |
| 高德地图 | `GAODE_API_KEY` | POI/路线 |

## 8. 可观测性设计

### 8.1 健康检查

```
健康检查层级:
┌─────────────────────────────────────────┐
│  Liveness Probe (存活探针)               │
│  - 检查进程是否存活                      │
│  - HTTP GET /health                     │
│  - 失败: 重启容器                        │
└─────────────────────────────────────────┘
            │
            ▼
┌─────────────────────────────────────────┐
│  Readiness Probe (就绪探针)               │
│  - 检查依赖服务是否可用                   │
│  - 检查 MySQL 连接                       │
│  - 检查 MCP Server 连接                  │
│  - 失败: 从负载均衡移除                   │
└─────────────────────────────────────────┘
```

### 8.2 指标监控

| 指标类别 | 指标名称 | 说明 |
|----------|----------|------|
| 业务 | session_count | 会话数 |
| 业务 | message_count | 消息数 |
| 业务 | tool_call_count | 工具调用次数 |
| MCP Server | weather_calls | Weather Server 调用 |
| MCP Server | poi_calls | POI Server 调用 |
| 熔断 | ratelimit_remaining | 限流余量 |
